# CONTRIBUTING

Bienvenue Les développeurs!

## Setup

1. Clone le repo
2. Backend: \python -m venv venv && source venv/bin/activate && pip install -r requirements.txt\
3. Frontend: \
pm install\

## Git Workflow

1. Créer branche : \git checkout -b feature/us-XX-description\
2. Développer et tester
3. Commit : \git commit -m \"feat: description\"\
4. Push : \git push origin feature/us-XX-description\
5. Créer PR sur GitHub

## Standards

- Python: PEP 8 + tests > 70% coverage
- JavaScript: ESLint + Prettier
- Code review requis avant merge

Pour plus de détails, voir docs/
